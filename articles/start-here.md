The golden path is the supported way to build and run things here. Following it means
the platform takes care of builds, deploys, observability and security for you.
Stepping off it is allowed, but then you own what the platform would have done.

Main areas, each with its own article:
- Languages: `goldenpath lookup languages`
- Building a web app or API: `goldenpath lookup web-app`
- Linters and fast feedback: `goldenpath lookup linters`
- Storing data: `goldenpath lookup storage`
- Calling services outside the company: `goldenpath lookup external-services`
- Configuration and secrets: `goldenpath lookup config-and-secrets`
- Logs, metrics and traces: `goldenpath lookup observability`
- Running on Kubernetes: `goldenpath lookup kubernetes`

Don't know where something fits? `goldenpath search <words>`.
